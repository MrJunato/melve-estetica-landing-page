# Melve Estética — Landing Page

## Ordem de execução
1. `docs/BRIEFING.md` → 2. `docs/ESCOPO_E_ORCAMENTO.md` → 3. aprovação do cliente → 4. estratégia/conversão → 5. direção visual → 6. implementação → 7. revisão do aspecto alterado → 8. publicação autorizada.
- Não implementar antes da aprovação de escopo e orçamento.
- Não publicar, contratar domínio/hospedagem, instalar trackers ou fazer deploy sem aprovação explícita.

## Escopo padrão
- Site estático, mobile-first, sem backend, sem painel, sem agendamento integrado, salvo contratação específica.
- Contato via link externo (ex.: WhatsApp) quando confirmado no briefing.
- Separe custos únicos (construção) de recorrentes (domínio, hospedagem, manutenção).

## Conteúdo e conformidade
- Instagram é referência, não autorização de uso de fotos/depoimentos.
- Não inventar serviços, preços, certificações, resultados, avaliações ou urgência.
- Marque evidência ausente como `[NEED: ...]` em vez de presumir.
- Sem dados de pacientes, sem alegação clínica, sem fotos geradas que sugiram local/equipe/resultado real.
- Português pt-BR, acessibilidade básica, imagens otimizadas, SEO essencial.

## Delegação econômica (sweet spot)
- `build`/`plan` resolvem o rotineiro diretamente.
- Chame `design` só para: identidade/composição ou problema visual concreto.
- Chame `conversion` só para: mensagem/sequência de seções/copy/CTA ou dúvida do caminho de contato.
- Antes do orçamento, só o mínimo para dimensionar; sem copy final nem layout final.
- Delegação sempre delimitada: objetivo + insumos + formato de resposta. Reutilize decisões aprovadas.
- Especialistas: recomendam, não editam, não executam shell, não delegam, não perguntam ao usuário (retornam pendências).
- Sem revisão em cascata e sem polimento iterativo sem motivo novo.
- Skills por etapa: criar visual → `frontend-design`; revisar UI → `web-design-guidelines`; textos → `copywriting`; estrutura/CTA → `cro`.

## Evidências
- Responda conciso: o que foi feito, arquivos/linhas, o que foi verificado de fato, pendências.
- Não apresente clique em contato como cliente conquistado nem prometa lift de conversão.
